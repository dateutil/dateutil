Fixed `relativedelta.__ne__` returning `False` for operands that `__eq__` does not handle, so that `relativedelta(days=1) != None` and `relativedelta(days=1) == None` were both `False`. On Python 3.9+ the old code additionally emitted a `DeprecationWarning` for evaluating `NotImplemented` in a boolean context. Reported by @robsdedude (gh issue #1157).
